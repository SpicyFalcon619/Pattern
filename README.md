# Pattern

C programs that print **patterns** with nested loops, from my first programming course (Structured Programming Language, CSE 1111, United International University).

The root folder has 28 pattern programs. Each file's top comment shows the pattern it prints:

- triangles and pyramids of stars, numbers and letters, including reversed, hollow and gapped versions
- squares and rectangles, rhombus
- Floyd's triangle, odd-number triangle, repeating sequences

`SPL Problem Set/` holds the course's numbered problem set (`1.c` onwards).

```bash
gcc FloydsTriangle.c -o floyd && ./floyd
```

Part of a small set with [Array](https://github.com/SpicyFalcon619/Array) and [Loop](https://github.com/SpicyFalcon619/Loop). Practice code, kept for reference.
